# 🎨 设计规范：梦幻柔彩主题

> 本文档是界面的「风格手册」：配色、字体、尺寸、动效，以这里为准。
> 改界面之前必须先读本文档，新样式必须沿用已有变量与节奏。

## 1. 风格总述

- **关键词**：梦幻、柔彩、粉紫渐变、马卡龙、圆润、轻盈
- 大背景浅粉白，前景卡片纯白，点缀粉 / 紫 / 金三色渐变
- 一切可点元素圆角拉满；阴影统一带粉色光晕
- 装饰元素：背景柔光斑（blur 光球）+ 缓慢漂浮的小星星

## 2. CSS 变量主题表（style.css 的 :root）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#FFF7FB` | 页面背景（浅粉白） |
| `--card` | `#FFFFFF` | 卡片背景 |
| `--pink1` | `#FF9EC4` | 主粉（渐变起点、强调色） |
| `--pink2` | `#FFD9EC` | 浅粉（悬停、光斑） |
| `--purple` | `#C9B6FF` | 主紫（渐变终点） |
| `--purple-deep` | `#9B7BD8` | 深紫（小评语文字，保证白底可读性） |
| `--gold` | `#F5C56B` | 金色（指针、星星、S 级） |
| `--ink` | `#5A4A66` | 正文文字（紫灰） |
| `--ink-soft` | `#9A8AAB` | 次要文字（浅紫灰） |
| `--border-soft` | `#F3D9E8` | 边框 / 虚线（浅粉） |
| `--radius` | `20px` | 通用圆角 |
| `--shadow` | `0 12px 32px rgba(255,150,200,.18)` | 通用粉色阴影 |

**规则**：新增颜色优先复用变量；确需新颜色时先加变量再用，不在样式里硬编码。

## 3. 字体

```css
font-family: "Yuanti SC", "YouYuan", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

- 全站统一这一个字体栈（圆体优先，系统自带，零网络依赖）
- 标题渐变色文字：`linear-gradient(135deg, #FF7FB0, #B79BFF)` + `background-clip: text`
- 按钮必须写 `font-family: inherit`（否则浏览器默认字体）

## 5. 动效参数（改动必须沿用节奏）

| 动效 | 参数 |
| --- | --- |
| 转盘旋转 | 4200ms，`cubic-bezier(0.17, 0.67, 0.12, 0.99)`（先快后慢） |
| 星星漂浮 floaty | 6s ease-in-out 无限循环，上浮 14px + 旋转 20° |
| 当前格呼吸 pulse | 1.6s ease-in-out 无限循环，光晕 3px→9px |
| 填格弹跳 pop | 0.45s `cubic-bezier(.34, 1.56, .64, 1)`，scale .55→1.1→1 |
| 落定提示 toastPop | 1.7s `cubic-bezier(.34, 1.56, .64, 1)`，scale .3→1.06→1 弹入，78% 后淡出 |
| 弹层淡入 | opacity .3s；卡片入场 .35s 回弹曲线，translateY 24px→0 + scale .96→1 |
| 通用过渡 | 颜色/阴影/透明度 .15~.3s |

## 6. 等级配色（渐变文字）

| 等级 | 渐变 |
| --- | --- |
| S | `#F7C86B → #E8964A`（金） |
| A+ / A | `#FF8FB8 → #FF5C9E`（粉） |
| B+ / B | `#C9B6FF → #9B7BD8`（紫） |
| C+ / C | `#A8B8CC → #7E93AB`（蓝灰） |
| D | `#B0B0B0 → #8A8A8A`（灰） |

## 7. 响应式断点

- 断点：**max-width 760px**（手机竖屏）
- 移动端变化：标题 24px；布局改纵向排列；转盘 320px；属性格 4 列 × 74px、间距 8px、最小高 92px、等级字 26px；结果卡 padding 26px 18px、总评字 58px
- 转盘文字会随扇区数自动缩放，勿在媒体查询里写死转盘字号
