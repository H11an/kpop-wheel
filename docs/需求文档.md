# 📝 需求文档：我的专属偶像生成器

> 本文档是产品的「说明书」：游戏应该做成什么样，以这里为准。
> 任何需求变更，请先在文末「需求变更记录」登记，再动代码。

## 1. 项目简介

一个纯网页小游戏：通过转盘随机抽取现役韩娱偶像组合、成员和属性，逐格填写 8 项属性，最终拼出「属于你的专属偶像」并给出总评。

- **玩法性质**：娱乐向、随机性、收集感
- **使用者**：零编程基础玩家，双击打开即玩
- **运行方式**：双击 `index.html`，无需安装任何软件

## 2. 核心玩法

### 2.1 三级转盘流程（逐格完成）

每填一格属性，完整走一遍三个步骤：

1. **转组合转盘**：从 18 个组合中随机转出 1 个
2. **转成员转盘**：从该组合的成员中随机转出 1 位
3. **转属性转盘**：从「尚未抽取」的属性中随机转出 1 项
4. 系统把该成员在该属性上的等级，自动填入当前属性格

重复以上流程，直到 8 个属性格全部填满，自动弹出偶像卡。

> 特殊规则：当只剩最后一个未抽取属性时（即填最后一格），转完成员后**自动填入**该属性，不再转动属性盘。

### 2.2 允许重复

同一组合、同一成员可以出现在多个属性格里（转盘不排除已用过的组合/成员），这样才会出现「饭撒 S 的娜琏 + 颜值 S 的娜琏」这类有趣的同成员多格结果。

### 2.3 重新抽取（重抽）——已于 2026-09-12 移除

> 历史记录：原版本中已填好的格子右下角有 ↺ 按钮，可清空该格重新抽取。
> 2026-09-12 按用户要求移除：**转出即定，不得再修改**（详见文末需求变更记录）。

## 3. 等级体系

等级从高到低：**S > A+ > A > B+ > B > C+ > C > D**

| 等级 | 数值（用于计算总评） |
| --- | --- |
| S | 100 |
| A+ | 95 |
| A | 90 |
| B+ | 85 |
| B | 80 |
| C+ | 75 |
| C | 70 |
| D | 60 |

数据约束（已确认）：
- **不出现 D 等级**
- 每位成员 **最多 1 项 C+/C**（避免「全废成员」破坏体验）
- 评分为娱乐向，基于大众认知，不保证专业客观

## 5. 总评 / 出道评级 / 趣味称号

8 格填满后自动弹出偶像卡，展示：

1. **总评等级**：8 项数值取平均分，就近映射到字母等级（分数相同时取更高的等级）
2. **出道评级**（按平均分）：

   | 平均分 | 评级 |
   | --- | --- |
   | ≥ 96 | 传奇级出道 |
   | ≥ 92 | 顶配出道 |
   | ≥ 88 | 高位出道 |
   | ≥ 84 | 顺滑出道 |
   | ≥ 80 | 顺利出道 |
   | ≥ 76 | 逆袭出道 |
   | ≥ 72 | 养成系出道 |
   | < 72 | 热血出道 |

3. **趣味称号**（优先级从上到下）：
   - 六边形战神·天选（8 项全 ≥ 95）
   - 六边形战神（8 项全 ≥ 85）
   - 偏科战神·X（最高项 ≥ 95 且最低项 < 80，X = 最高项的趣味称号）
   - ACE 预定·X（平均分 ≥ 88）
   - 潜力新星（平均分 ≥ 85）
   - 稳步上升（平均分 ≥ 80）
   - 养成之光（平均分 ≥ 75）
   - 未来可期（其余）

4. **详情清单**：每格来自哪位成员 · 哪个组合（几代）+ 等级

偶像卡底部有「🎀 再来一局」按钮，一键重开。
