# 📝 需求文档：我的专属偶像生成器

> 本文档是产品的「说明书」：游戏应该做成什么样，以这里为准。
> 任何需求变更，请先在文末「需求变更记录」登记，再动代码。

## 1. 项目简介

一个纯网页小游戏：通过转盘随机抽取现役韩娱偶像组合、成员和属性，逐格填写 8 项属性，最终拼出「属于你的专属偶像」并给出总评。

- **玩法性质**：娱乐向、随机性、收集感
- **使用者**：零编程基础玩家，双击打开即玩
- **运行方式**：双击 `index.html`，无需安装任何软件

## 2. 核心玩法

### 2.1 三级转盘流程（逐格完成）

每填一格属性，完整走一遍三个步骤：

1. **转属性转盘**：从「尚未抽取」的属性中随机转出 1 项
2. **转组合转盘**：从 18 个组合中随机转出 1 个
3. **转成员转盘**：从该组合的成员中随机转出 1 位
4. 系统把该成员在该属性上的等级，自动填入当前属性格

重复以上流程，直到 8 个属性格全部填满，自动弹出偶像卡。

> 特殊规则：当只剩最后一个未抽取属性时（即填最后一格），进入该格时**自动选定**该属性（不再转动单扇区属性盘），只转组合、成员两盘。

> 显示细节：转完属性盘后，当前格子的「待抽取」**立即替换**为该属性名（粉色加粗），待成员落地填格后才显示等级与来源。

> 落定提示：每次转盘停稳的瞬间，转盘中央弹出动画文字宣布抽中结果（如「✨ 抽中属性：舞蹈」「🌟 抽中成员：娜琏」），约 1.7 秒后自动淡出。

### 2.2 允许重复

同一组合、同一成员可以出现在多个属性格里（转盘不排除已用过的组合/成员），这样才会出现「饭撒 S 的娜琏 + 颜值 S 的娜琏」这类有趣的同成员多格结果。

> 历史记录：原版本中已填好的格子右下角有 ↺ 按钮，可清空该格重新抽取。

## 3. 等级体系

等级从高到低：**S > A+ > A > B+ > B > C+ > C > D**

| 等级 | 数值（用于计算总评） |
| --- | --- |
| S | 100 |
| A+ | 95 |
| A | 90 |
| B+ | 85 |
| B | 80 |
| C+ | 75 |
| C | 70 |
| D | 60 |

数据约束（已确认）：
- **不出现 D 等级**
- 每位成员 **最多 1 项 C+/C**（避免「全废成员」破坏体验）
- 评分为娱乐向，基于大众认知，不保证专业客观

## 5. 总评 / 出道评级 / 趣味称号 / 小评语

8 格填满后自动弹出偶像卡，展示：

1. **总评等级**：8 项数值取平均分，就近映射到字母等级（分数相同时取更高的等级）
2. **出道评级**（按平均分）：

   | 平均分 | 评级 |
   | --- | --- |
   | ≥ 96 | 传奇级出道 |
   | ≥ 92 | 顶配出道 |
   | ≥ 88 | 高位出道 |
   | ≥ 84 | 顺滑出道 |
   | ≥ 80 | 顺利出道 |
   | ≥ 76 | 逆袭出道 |
   | ≥ 72 | 养成系出道 |
   | < 72 | 热血出道 |

3. **趣味称号**（优先级从上到下）：
   - 六边形战神·天选（8 项全 ≥ 95）
   - 六边形战神（8 项全 ≥ 85）
   - 偏科战神·X（最高项 ≥ 95 且最低项 < 80，X = 最高项的趣味称号）
   - ACE 预定·X（平均分 ≥ 88）
   - 潜力新星（平均分 ≥ 85）
   - 稳步上升（平均分 ≥ 80）
   - 养成之光（平均分 ≥ 75）
   - 未来可期（其余）

4. **小评语**：按出道评级分层（共 8 档），每档一组风趣评语、随机展示一条；**评语会点名本次结果的最强属性与最弱属性**（如「舞蹈强到封神，说唱弱到被队友当场补习」），八项无强弱差（六边形）时改用均衡类评语（如「六边形天花板，找短板？不存在的」）
5. **详情清单**：每格来自哪位成员 · 哪个组合（几代）+ 等级

偶像卡底部有「🎀 再来一局」按钮，一键重开。

## 6. 分享与保存

结果卡底部提供「📤 分享」与「💾 保存图片」：

- **分享链接（微信/朋友圈）**：调用系统分享面板（`navigator.share`），手机上可选微信、朋友圈；链接携带完整结果（`#r=` 哈希），朋友点开直接看到同一张偶像卡（卡片头部显示「朋友分享的偶像卡」）；不支持系统分享的设备自动降级为复制链接
- **分享到小红书**：一键复制「结果摘要文案 + 链接」，到小红书粘贴发布
- **保存图片**：原生 Canvas 自绘结果卡生成 PNG；iOS 走系统分享面板「存储图像」存入相册，其他设备直接下载
- 「再来一局」清除分享状态，回到正常开局
