# 🎬 抖音特效制作指南（Kpop偶像转盘 · 转盘+偶像卡版）

> 前置条件：已完成 ① 抖音特效开放平台注册+实名 ② 安装 Effect House（抖音定制版）
> 交付物位置：项目 `抖音特效/` 文件夹（素材 + 核心逻辑.js + 特效脚本完整版.ts）

## 0. 特效玩法（简化版）

拍视频时画面下方有一个 28 团转盘 → 自动旋转（或点击屏幕触发）→ 停下弹出偶像卡：
`组合 · 成员 · 属性+等级 · 称号`，停留几秒后自动开始下一轮，可一直录。

**只用文字，不用偶像照片**（肖像权是审核红线）。

## 1. 新建工程

1. 打开 Effect House → 新建空白工程（New Project → 选「Blank」或任意 2D 模板）
2. 保存工程到任意位置

## 2. 导入素材（抖音特效/素材/ 文件夹）

1. 在左侧「Assets」面板点 + → Import，把 5 张图全部导入：
   - `转盘.png`（1024×1024，28 扇区带团名）
   - `指针.png`（160×200 金色指针）
   - `hub.png`（200×200 中心圆）
   - `偶像卡底版.png`（720×960 卡片，透明底）
   - `图标.png`（512×512，提交审核用）

## 3. 搭建场景（Hierarchy 面板）

按顺序添加 2D 对象并拖入贴图：

| 对象 | 用什么图 | 位置/大小（预览面板里拖动调整） |
| --- | --- | --- |
| 转盘 | 转盘.png | 屏幕下半部，占屏宽约 75%，圆形比例 1:1 |
| 指针 | 指针.png | 叠在转盘正上方（针尖向下指着转盘顶部） |
| 中心圆 | hub.png | 转盘正中心，直径约转盘 18% |
| 卡片 | 偶像卡底版.png | 屏幕中央，宽约 65%，初始设为隐藏（Visible 关） |
| 文字×4 | 无图，用 Text 组件 | 叠在卡片上：组合行（大）/ 成员行（大）/ 属性+等级行（中）/ 称号行（小） |

> 文字组件样式：白色或深紫 `#5A4A66`、居中、圆体；初始隐藏。

## 4. 挂脚本（核心一步）

1. 选中任意对象 → Inspector 面板 Add Component → 选 **Script**（新建脚本）
2. 编辑器会打开自动生成的模板 .ts 文件
3. 打开项目里的 `抖音特效/特效脚本完整版.ts`，**全选复制**，把编辑器模板**整个替换**
4. ⚠️ 如果编辑器模板的第一行 `import ...` 与脚本里不同：保留编辑器的 import 行，只替换其余内容
5. 在 Inspector 的脚本组件里把四个 Text 对象和转盘对象拖进对应的 @input 槽位
6. ⌘+S 保存 → 预览面板立即生效

> 默认 `autoSpin = true`：不接任何手势也会自动循环抽卡，预览即可看到完整效果。

## 5. （可选升级）点击屏幕才抽卡

1. 把脚本里 `private autoSpin = true;` 改为 `false`
2. 触发方式二选一：
   - 在编辑器脚本 API 里搜索手势/touch 事件，回调中调用 `this.doSpin()`（以编辑器自动补全为准）
   - 或从官方「点击触发」模板工程开始搭建（模板自带手势接线）

## 6. 预览与真机测试

1. 桌面预览：确认转盘转、卡片弹出、文字正确、循环正常
2. 真机：Effect House 顶部「发送到手机」→ 抖音 App 扫二维码 → 实拍测试
3. 检查：文字清晰不超卡面、转盘不遮挡人脸（建议转盘放屏幕下半部）

## 7. 提交审核

1. Effect House 顶部「Export/上传」→ 按提示填写：
   - **名称**：Kpop偶像转盘
   - **图标**：素材里的 `图标.png`
   - **简介**：
     > 随机转盘测出你的专属Kpop偶像！转盘转一转，组合、成员、属性、称号一次集齐，看看你的本命配置有多顶！纯娱乐，测着玩～
   - 分类：随机测试 / 娱乐
2. 提交后等待审核（一般 1~3 天）；如被驳回，按驳回原因修改后重新提交
3. 上架后：自己先拍一条示范视频发布，特效会挂在你视频上，观众点「拍同款」自动扩散

## 8. 常见问题

- **@input 报错**：Effect House 版本差异，按编辑器脚本模板的字段写法接线即可（逻辑调用点不变）
- **旋转不生效**：确认转盘对象已拖进 wheelImage 槽位；ScreenTransform 旋转 API 以编辑器为准
- **审核被拒**：优先排查是否用了偶像照片/logo；纯文字版本通常可通过
- **数据要更新**（以后加了新团）：运行 `node 抖音特效/生成脚本.js` 重新生成脚本后替换
